<h1 align="center">BrowserSpoof</h1>

<p align="center">
  Browser launcher with customizable fingerprint settings built with Python and Selenium.
</p>

## ✨ Features

- 🌍 Location & timezone spoofing
- 🖥 Chrome, Firefox and Edge support
- 🌐 HTTP and SOCKS5 proxies
- 📱 Custom and random User-Agents
- 🔒 WebRTC blocking
- 📐 Custom resolutions
- 🌙 Dark and light themes
- 👻 Headless mode
- 🕶 Incognito mode
- 📦 Extension loading
- 💾 Presets system
- 🎮 Discord Rich Presence

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/Dopa/BrowserSpoof.git
cd BrowserSpoof
```

Install dependencies:

```bash
pip install selenium rich pyfiglet pypresence
```

---

## 🚀 Usage

Start BrowserSpoof:

```bash
python BrowserSpoof.py
```
